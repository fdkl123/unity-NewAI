# 6-Week Roadmap

## Week 1: Bootstrapper Foundations

- Define `unity-ai new` onboarding session schema.
- Implement first-round questionnaire and answer normalization.
- Define generated artifact templates.
- Implement confirmation preview contract.

## Week 2: Diagnosis and Skill Resolution

- Implement project type and complexity diagnosis.
- Implement architecture recommendation rules.
- Implement AI skill resolver.
- Generate `project-brief.md`, `ai-skills.md`, `risk-register.md`, and `mvp-plan.md`.

## Week 3: Scaffold Manifest and Writer

- Generate deterministic `scaffold-manifest.json`.
- Create Unity-friendly directory structure after confirmation.
- Create baseline conductor files.
- Add default verification and performance-budget artifacts.

## Week 4: Project Cognition Scan

- Implement Unity repository scanner prototype.
- Implement planning-document discovery and project cognition summary.
- Build context pack generation for Unity scripts, settings, packages, and docs.
- Add source-linked context trace to downstream tasks.

## Week 5: Performance Analyzer

- Implement static performance analyzer rules.
- Detect update-loop lookups, GC allocations, object lifecycle churn, and physics hot paths.
- Generate recommendations with severity, file-level evidence, and expected metric impact.
- Add patch-proposal mode for narrow optimization patterns.
- Add gameplay-intent guard for behavior-changing optimization risks.

## Week 6: Verification and Demo

- Implement verification gate registry and runner.
- Parse gate output into structured evidence.
- Implement bounded self-healing diagnosis and retry flow.
- Create Bootstrapper-to-performance demo fixture.
- Add regression tests for analyzer rules and schemas.
- Build CLI demo flow.
- Write installation, usage, and limitations documentation.
